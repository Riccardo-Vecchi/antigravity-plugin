# Official application icons

Gemini: https://www.gstatic.com/lamda/images/gemini_sparkle_4g_512_lt_f94943af3be039176192d.png (favicon declared by gemini.google.com)

Antigravity: https://antigravity.google/favicon.svg

Downloaded on 26 October 2026. Original assets; no visual edits.

`icons/antigravity.png` is the application icon from the official Antigravity App 2.26.0 Linux AppImage. `icons/gemini-*.png` are resized versions of the Gemini website favicon listed above. Source assets remain separate from generated runtime display files.

`icons/antigravity.ico` and `icons/gemini.ico` are Windows ICO containers holding the corresponding 256px PNG asset, with no visual changes.

`assets/windows.svg` is a minimal four-pane platform indicator drawn for this repository to identify Windows; the Windows name and platform mark belong to Microsoft.
